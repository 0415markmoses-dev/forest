# Dark Themed Modern Portfolio

🌙 A beautiful, modern portfolio website with a sleek dark theme, built with React and Tailwind CSS.

## Features

✨ **Modern Design** - Clean, minimalist dark theme with smooth animations  
🎨 **Fully Responsive** - Works perfectly on all devices  
⚡ **Fast Performance** - Optimized for speed and lighthouse scores  
🔧 **Easy Customization** - Simple to personalize with your own content  
📱 **Mobile Friendly** - Touch-optimized mobile navigation  
🚀 **Vercel Ready** - One-click deployment to Vercel  

## Sections

- **Header** - Fixed navigation with smooth scroll
- **Hero** - Eye-catching introduction section
- **About** - Your story and background
- **Skills** - Technical skills with progress bars
- **Projects** - Showcase of your work
- **Contact** - Get in touch form and contact info
- **Footer** - Simple footer with credits

## Quick Start

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd dark-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

The app will open at [http://localhost:3000](http://localhost:3000)

## Customization

### Update Your Information

Edit `src/components/Hero.js` to update:
- Your name and title
- Professional summary
- Social media links

### Add Your Skills

Modify the `skillsData` array in `src/components/Skills.js`

### Showcase Your Projects

Update the `projectsData` array in `src/components/Projects.js` with your projects

### Customize Colors

Edit `tailwind.config.js` to change the dark theme colors and gradients

## Technologies Used

- **React** - UI library
- **Tailwind CSS** - Utility-first CSS framework
- **React Icons** - Icon library
- **React Scroll** - Smooth scrolling
- **AOS (Animate On Scroll)** - Scroll animations
- **PostCSS** - CSS processing

## Deployment

### Deploy to Vercel

1. Push your code to GitHub
2. Visit [vercel.com](https://vercel.com)
3. Import your repository
4. Vercel will auto-detect the settings
5. Click "Deploy"

### Using Vercel CLI

```bash
npm install -g vercel
vercel
```
